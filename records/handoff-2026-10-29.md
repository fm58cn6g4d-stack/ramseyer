## Revised order of work (approved 2026-10-29)

1. **Foundations:**
   - USLM 1.x and 2.x (namespace-agnostic indexer and xmltext; OLRC's 2.0.12 sample titles in aih/uscode-redesign `samples/uslm2`);
   - the Comparative Print Suite's four failure categories, including "already executed into current law";
   - incorporated-set release-point windows (`not` and `u1` labels).
2. **Rebuild the oracle on dreamproit/uscode** (381 release points, 2013–2026; about 3 GB of Parquet), with three additions:
   - GPO `amendingAction`/`ref` tagging as a second reader;
   - draft versions (introduced and reported) of enacted laws graded against the enacted change;
   - dry-run of amendments to Act text quoted in Code notes.
3. **The Act-text layer:**
   - load the Statute Compilations (about 2,710, USLM, GovInfo `bulkdata/json/COMPS`; each states `currentThroughPublicLaw`);
   - run each draft against both the Act and the Code, and compare the two results.
4. **M8 comparative print**, with two displays chosen per provision:
   - a redline for amendments to existing text;
   - a structure-and-placement view for new statute.

   Check it against the "changes in existing law" sections of committee reports.
5. **Later:** bill-to-bill and amendment-to-bill comparison; bill viewer features.

## Moving to its own repository (done 2026-10-29)

**History:** keep it by splitting the subdirectory's history. The path was `billmap/` before 11d48a3 and `ramseyer/` after, so use `git filter-repo --path billmap/ --path ramseyer/ --path-rename billmap/:` and `--path-rename ramseyer/:`, or `git subtree split` on each path. Then push to the new repository's main.

**Instructions:** the project-2050 root `CLAUDE.md`/`AGENTS.md` workflow (queue, PR tiers, Agent-Author lines) no longer applies. `ramseyer/CLAUDE.md` becomes the root instructions.

**Data:** `.env` and `var/` are local only. Copy `.env` by hand; rebuild `var/` with the scripts.
